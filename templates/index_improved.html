Follow the lessons on the left panel to learn Linux, Python, and Rust. Start with Lesson 1 and progress at your own pace. Each lesson includes examples you can try in the terminal.

Use the "Help" and "Quick Commands" tabs for reference. You can copy commands with one click! Check out the "Student Tools" tab for special classroom commands.

File & Directory Operations

ls

List files and directories

ls -la
cd

Change directory

cd /home/student
pwd

Print working directory

pwd
mkdir

Create directory

mkdir my_folder
touch

Create empty file

touch file.txt
cp

Copy file or directory

cp file.txt backup.txt
mv

Move or rename file

mv old.txt new.txt
rm

Remove file

rm file.txt

View & Edit Files

cat

Display file content

nano

Simple text editor

vim

Advanced text editor

less

View file page by page

less long_file.txt
