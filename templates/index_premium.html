File Operations

List Files
Display files and directories in current location
ls -la
Change Directory
Navigate to a different directory
cd /home/student
Create Directory
Make a new directory/folder
mkdir my_project
Create File
Create an empty file or update timestamp
touch file.txt
View File
Display file contents in terminal
cat file.txt
Copy File
Duplicate files or directories
cp source.txt destination.txt

Text Editors

Nano Editor
Simple, beginner-friendly text editor
nano filename.txt
Vim Editor
Powerful, advanced text editor
vim filename.txt

System Information

Current Directory
Show your current location in filesystem
pwd

whoami
